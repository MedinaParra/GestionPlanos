Qué sigue protegido

El STEP original no se publica. El portal recibe únicamente una representación visual de baja fidelidad geométrica. El archivo público puede descargarse, pero no es el CAD de ingeniería.

Con GitHub Pages no es posible impedir técnicamente que alguien descargue un recurso que el navegador necesita. La defensa correcta es que el recurso descargable no contenga la propiedad intelectual crítica.
